# Changelog

All notable changes to this project are recorded here, one section per milestone.

## [Unreleased] — Milestone 4 (model training and evaluation)
- Added `docs/milestones/M4/Milestone4_Report.md` and PDF (the course team's 12-section outline, the repair validation layer, team sign-off page), `Milestone4_Worklog.md`, `sample_outputs.md`, the AI usage disclosure (report, last section before the sign-off), and the review deck (`ContextGuard_M4_Slides.pptx` and PDF) in `docs/milestones/M4/slides/`.
- Training: `src/llm/train_lora.py` gains early stopping, `--epochs`, `--n-train`, `--exclude-synthetic`, `--weight-decay`, `--schedule`, `--max-hours` and `--val-seed`; the best adapter and the last adapter are saved separately and the best one is reloaded to check its loss. `scripts/eval_adapters.py` scores every adapter on one shared validation sample; `scripts/run_m4_screening.sh` runs the screening runs. The full run, 11 screening runs and 2 seed runs are in `docs/tables/m4_training_runs.csv`, `m4_f1_train_log.csv`, `m4_fixed_val_eval.csv`.
- Run records and analysis (Jashan): one config per run in `configs/m4_*.yaml` (`scripts/generate_configs.py`), `scripts/plot_training.py` (runs table, seed spread, loss figures in `docs/figures/m4/`), `scripts/check_rule_validity.py` (stage 0 rules checked on the clean table), `scripts/pick_examples.py` (sample outputs), `docs/tables/m4_hparam_runs.csv`, `m4_seed_spread.csv`, `m4_rule_validity*.csv`, `m4_sample_outputs.csv`, `m4_training_artifacts.csv`, `tests/test_m4_jashan.py`.
- Stage 1: the format detector D7 (`src/detectors/d7_format_mix.py`, replaces the stage 0 rules detector) and the D5 entity-consensus extension (`src/detectors/d5_entity_consensus.py`), both computed from the dirty table only, with `tests/test_m4_detectors.py`. Stage 0 is switched off (`--stage0-rules`) after experiment E6. Table-specific parts removed from `src/detectors/d2_pattern.py` (Aaradhya).
- Stage 2 and 3: `src/profiling/context.py` finds the entity key from the data and shows the reliability-weighted consensus of the entity in the prompt; `src/llm/infer.py` returns the confidence of the repair value (lowest token probability), used by the gate (`repair_confidence` 0.9).
- Repair validation layer: `src/validation/repair_validator.py`, independent rule files in `configs/validation/` (each rule names its source), `scripts/validate_repairs.py`, `run_pipeline.py --validate`, `tests/test_repair_validator.py`.
- Experiments: `scripts/run_pipeline.py` (new flags, `gate_decision`), `scripts/run_m4_pipeline_runs.sh`, `run_m4_variants.sh`, `run_m4_final_eval.sh`, `configs/m4_final_pipeline.yaml`; E3 and E6 tables (`scripts/build_m4_experiments.py`), candidate recall and missed errors (`scripts/evaluate_m4_candidates.py`, `analyze_missed_errors.py`, Aaradhya); results in `docs/tables/m4_pipeline_runs.csv`, `m4_inference_variants.csv`, `m4_validation_comparison.csv`, `m4_e3.csv`, `m4_e6.csv`, `m4_candidate_recall.csv`, `m4_missed_errors.csv`.
- Baselines on the test splits (simplified versions, Raha labels exactly our 20 rows with a fixed seed): `scripts/run_baselines_full.py`, `run_baselines_m3_simplified.py` (the M3 script, kept), `docs/tables/m4_baselines_full.csv`; ContextGuard scored on the same cells with `scripts/score_like_baselines.py`, `scripts/build_test_vs_baselines.py`, `docs/tables/m4_test_vs_baselines.csv`.
- Evaluation (Sahilpreet): `score_decisions` in `src/evaluation/metrics.py` (every cell counted once; gate decision and final decision scored separately), the EM prior estimate and `fit_gate` in `src/evaluation/calibrate.py`, `scripts/fit_calibration.py`, `scripts/rescore_m3_gate.py`, `configs/m4_calibration_study.yaml`, `docs/tables/m4_calibration.csv`, `m4_outcomes_*.csv`, `m3_rescored_gate.csv`, `docs/figures/m4/reliability_diagram.png`, `tests/test_m4_sahilpreet.py`.
- Changed: `scripts/score_run.py` writes `outcomes.csv`; `scripts/run_baselines.py` now points to the M4 baseline script.

Error status, repairs, splits, prompts and example counts are unchanged; `train.jsonl`, `val.jsonl` and `test.jsonl` changed (new SHA-256 prefixes `99e3cdf9`, `e8f75de3`, `16c3dee4`).
